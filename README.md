# Generative-AI
Generative AI 
This repository contains a collection of hands-on Generative AI experiments and applications implemented in Python. The work focuses on building practical understanding of large language model workflows, chatbot development, LangChain-based applications, Retrieval-Augmented Generation systems, document processing, vector-based retrieval, agent workflows, and RAG evaluation.

The repository includes both notebook-based experiments and Python scripts developed through practical coding exercises. The main focus is on learning how Generative AI applications are built step by step, from basic OpenAI API usage and chatbot development to more advanced RAG pipelines using document loaders, text splitters, embeddings, vector stores, hybrid search, graph-based retrieval, and evaluation with RAGAS.

Repository Structure

Chatbot/
Basic chatbot implementations using LangChain and the OpenAI API.

LangChain/
Experiments with LangChain components, including document loaders, text splitters, RAG pipelines, agents, hybrid search, Neo4j graph-based retrieval, and RAG evaluation.

Documents/
Sample PDF, TXT, CSV, HTML, and DOCX files used for testing document loading, retrieval, and question-answering workflows.

RAG Applications/
Notebook-based implementations of Retrieval-Augmented Generation systems, including simple RAG, conversational RAG, hybrid search RAG, and LangChain-based RAG apps.

Evaluation/
RAGAS-based evaluation examples for assessing RAG outputs using metrics such as faithfulness, answer relevancy, context precision, and context recall.

Notes

The code and notebooks in this repository are organized as learning experiments rather than polished production systems. Each notebook or script focuses on a specific Generative AI concept or workflow, with explanatory comments and practical examples to support understanding.

This repository is intended for learning, experimentation, and reference in Generative AI, LangChain, chatbot development, and Retrieval-Augmented Generation.
